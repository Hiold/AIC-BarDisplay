# 横屏显示改造（内存安全版）说明 — landscape-mode 分支

> 目标：把竖条副屏固件改为**横屏显示**，且**不放大 framebuffer**，保证 8 MiB PSRAM 下屏亮、USB 可识别。

## 背景：第一次尝试为什么失败

第一版通过驱动级 **fb 旋转**（AIC_FB_ROTATE_EN + AIC_FB_ROTATE_DEGREE=90）实现横屏，
但 aicfb_calc_fb_size()（drv_fb.c）会按 fb_size*(1+AIC_FB_DRAW_BUF_NUM) 把 framebuffer 放大到 3 份。
以 boe1126（440x1920）计：单份约 2.53 MiB * 3 = 约 7.6 MiB，而 PSRAM 仅 8 MiB（CMA 约 7 MiB）→ OOM。
于是 aicfb_probe 分配失败 → 无扫描输出（屏幕不亮）+ 初始化级联异常 → USB 不识别。
已回退（提交 c36af9a）。本版不再使用 fb 旋转。

## 本版设计（内存安全）

物理面板扫描保持竖条（单份 framebuffer，屏能亮、USB 能枚举），横屏通过 VE/JPEG 解码旋转实现：

    host / 空闲视频 → 横屏 JPEG（宽>高，如 1920x480）
        └─ VE 解码器 rotate（MPP_ROTATION_90，解码时旋转）
           ▼
        竖条 NV12（如 440x1920）铺满竖条面板（复用 NV12 双表面，无额外大块内存）

| 环节 | 做法 | 文件 |
| --- | --- | --- |
| 配置 | 仅新增 AIC_USB_DISP_ROTATION_FULLSCREEN 1，**不启用** AIC_FB_ROTATE | firmware/configs/*.h（10 个 app 变体） |
| 解码 | udisp_decoder_open() 设 MPP_DEC_INIT_CMD_SET_ROT_FLIP_FLAG = MPP_ROTATION_90；udisp_decode 仍用竖屏 udisp_screen 门控/居中/裁剪 | display.c |
| USB 能力 | 能力串 R<WxH>、HID 报告、RX 帧头校验改用互换的横屏宽高（host 按横屏发帧） | transport.c |
| UI | 保持竖屏 udisp_screen（尺寸/内存不变），浮层窗口定位不变 | ui.c（不改） |
| 视频资源 | 空闲视频重编码为横屏：assets/video → 1920x480、assets_av093x → 1280x320；加回 rebuild.py --rotate | video.bin/json、tools/video_rebuild/rebuild.py |

关键：AIC_USB_DISP_ROTATION_FULLSCREEN 只影响 mjpeg_decoder.c 的 stride 布局和被门控的解码器旋转，
不会像 AIC_FB_ROTATE 那样放大 framebuffer，故内存预算不变。

## 上机需核验

1. 旋转方向/角度：display.c 的 MPP_ROTATION_90 是否与画面方向一致。若倒置/镜像，在 0/90/270 之间调整 rotmir（并相应调整 --rotate 重编码方向）。若 VE 旋转对当前面片不可用，可将该变体摘掉 AIC_USB_DISP_ROTATION_FULLSCREEN 恢复竖屏原样。
2. USB 能力：host 应看到 R1920x440（boe1126）等横屏分辨率，并按横屏发 JPEG；设备解码旋转后显示。
3. 空闲视频：已重编码为横屏（1920x480 / 1280x320），与 host 帧走同一 VE 旋转。
4. UI 浮层：仍为竖屏 400x480 浮窗（内存约束），与旋转后的横屏视频叠加；如需 UI 也随内容旋转，需在 ui.c 增加 GE 硬件旋转（参考 lv_port_disp.c 的 LV_DISPLAY_ROTATE_GE_PARTIAL），属后续可选优化。

## 重新生成横屏视频
    python tools/video_rebuild/rebuild.py src_480x1920.bin out.bin --out 1920 480 --rotate 90
    python tools/video_rebuild/rebuild.py src_480x1920.bin av093x.bin --out 1280 320 --rotate 90

（工具依赖 Pillow；仓库自带 tools/python 未带 Pillow，可用带 Pillow 的解释器运行。）
